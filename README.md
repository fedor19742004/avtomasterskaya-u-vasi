# Автомастерская у Васи

Адаптивный лендинг автомастерской на HTML, CSS и JavaScript, без сборки и зависимостей.

## Файлы

- `dist/index.html` — содержание страницы.
- `dist/style.css` — оформление и адаптивная верстка.
- `dist/app.js` — окно записи и проверка формы.
- `.openai/hosting.json` — настройки текущего хостинга Sites.

## Просмотр

Откройте `dist/index.html` в браузере. Для шрифта Google Fonts и фотографии Unsplash нужен интернет.

## Форма записи

Форма демонстрационная: проверяет заполнение, но не отправляет и не сохраняет данные. Для реального приема заявок нужно подключить обработчик и добавить контакты мастерской.
